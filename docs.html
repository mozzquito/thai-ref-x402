Thai Reference API

$0.005 / call x402 - USDC - Base Sepolia no API key needed

Thailand reference data for AI agents & developers. Pay per request with x402 (HTTP 402) — no signup, no subscription, no API key. Base URL: https://api.thaical.xyz

Quickstart (30 seconds)

# reference endpoints (/fx, /gold, /is-business-day, /hs/search, ...) are FREE:
curl -i https://api.thaical.xyz/fx
# -> HTTP 200 + JSON data

# paid example — HS duty lookup ($0.005):
curl -i https://api.thaical.xyz/hs/lookup?code=42023200
# -> HTTP 402 + PAYMENT-REQUIRED header (the terms: amount, asset, payTo)
# Retry with the x402 payment header (any x402 client SDK does this automatically):
#   PAYMENT-SIGNATURE: <signed EIP-3009 payment>
# -> HTTP 200 + JSON data

Client SDKs: x402 Python/TS SDK. Payer only needs USDC on Base (EIP-3009 — the payer pays no gas).

Terms (machine-readable)

Paid endpoints (/hs/lookup) respond to unpaid requests with an HTTP 402 whose PAYMENT-REQUIRED header carries the full payment terms (x402 v2): scheme exact, asset USDC, network eip155:84532, amount 5000 (0.005 USDC), maxTimeout 300s. Settlement via Coinbase CDP facilitator. All reference endpoints are free — no 402.

Honesty notes

  • /gold is derived from international spot + ECB FX — NOT the Gold Traders Association posted price (stated in every response).
  • /fx follows ECB daily reference rates (no weekend updates).
  • /bank-business-day covers weekends + Thai public holidays; ad-hoc special bank closures not yet included.
