Thai bank settlement calendar,
free reference layer.

Thai public holidays ≠ Thai bank holidays. If your agent schedules THB payouts, one wrong day means a missed settlement. Reference endpoints (business days, FX, gold, /hs/search) are free; HS duty lookup is paid via x402; KYB & WHT coming.

Try it in 30 secondsMCP wrapper (MIT)

🧾 Pay per request

$0.005 per call, paid in USDC over x402. No subscription, no keys to leak, no vendor lock-in.

⚡ No gas for payers

Payments use EIP-3009 signatures — the payer's wallet spends zero ETH. The facilitator settles.

🤖 Agent-native

The 402 challenge carries machine-readable terms. MCP wrapper included for Claude, Cursor & friends.

🔎 Honest data

Every response labels its source and caveats. FX from ECB; holidays incl. substitution days, in Thai and English.

Endpoints

/bank-business-day?date=
Bank of Thailand business-day check — the settlement-calendar hero
/is-business-day?date=
Thai business day + holiday name (substitution days included)
/add-business-days?date=&n=
Skip weekends & Thai holidays forward
/fx
THB reference rates — USD/EUR/JPY/GBP/CNY (ECB daily)
/hs/search?q=
FREE — search 11,414 Thai HS codes; MFN duty on the top 3 hits
/hs/lookup?code=
PAID $0.005 — full HS record + MFN duty for one 8-digit code

Quickstart

# reference endpoints are FREE:
curl -i "https://api.thaical.xyz/bank-business-day?date=2026-12-31"
{"date":"2026-12-31","is_bank_business_day":false,"holiday_name":"วันสิ้นปี"}

# paid example — HS duty lookup ($0.005):
curl -i "https://api.thaical.xyz/hs/lookup?code=42023200"
# → HTTP 402 + PAYMENT-REQUIRED header  (0.005 USDC, payTo, Base)
# retry with PAYMENT-SIGNATURE (any x402 client SDK signs EIP-3009)
# → HTTP 200
